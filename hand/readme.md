# Hand - ручное P2P рукопожатие

Для случаев, когда мастер недоступен вовсе: локалка без интернета, hotspot с телефона в лесу. Offer и answer - обычные строки, транспорт для них любой: QR-код, мессенджер, AirDrop, буфер обмена. Камера, рендер QR и прочий UX остаются на стороне приложения - база отдаёт и принимает только строки.

## Использование

```ts
// Сторона A
const hand = $giper_baza_hand.make({})
const offer = await hand.proposal() // строку - мейту (например, QR)

// Сторона B
const hand = $giper_baza_hand.make({})
const answer = await hand.answer( offer ) // строку - обратно

// Снова сторона A
await hand.finish( answer ) // канал открывается, порт уходит в yard

hand.port() // реактивный статус: порт или null
```

После открытия канала порт регистрируется в `yard.peers` и синкает все общие ленды наравне с мастерами. Обрыв соединения обнуляет `port()` - для переподключения сторона A делает `reset()` и показывает новый QR.

Общая WebRTC-кухня (non-trickle переговоры, обвязка канала в порт) живёт в `port/webrtc` и разделяется с `room` - это две стратегии доставки одних и тех же двух строк: room везёт их юнитами через ленд, hand отдаёт наружу.
