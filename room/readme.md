# Room - прямой P2P синк

Пиры, встретившиеся в одной комнате, устанавливают прямые WebRTC-соединения и синкают все общие ленды напрямую, минуя мастеров.

## Как это работает

1. **Комната** - обычный ленд с правом post для всех (`$giper_baza_room_grab`). Никакой серверной логики: сигналинг едет через штатную синхронизацию этого ленда.
2. **Presence**: каждый пир раз в 20 секунд пишет атом `beat_{lord}` со своим временем. Кто писал недавно - тот онлайн (`mates()`).
3. **Роли**: для каждой пары ровно один пир делает offer - тот, у кого лорд лексикографически меньше (`$giper_baza_room_offerer`). Обе стороны вычисляют это локально.
4. **Сигналинг**: offerer собирает все ICE-кандидаты (non-trickle) и пишет атом `offer_{from}>{to}` с sdp и стампом. Второй пир видит его, отвечает атомом `answer_{from}>{to}` с тем же стампом. Стамп отличает свежий offer от протухшего после реконнекта.
5. **Канал**: после открытия DataChannel порт (`$giper_baza_port_webrtc`) добавляется в `yard.peers` и работает наравне с мастерами - обмен фейсами, доливка недостающих юнитов.
6. **Реконнект**: обрыв канала бампает счётчик `restarts`, offerer создаёт новое соединение с новым стампом. Атомы - LWW-регистры, новые сигналы затирают старые на месте.

Доверие прямому каналу не требуется: юниты подписаны, приватное зашифровано, каждый узел всё проверяет сам. Если WebRTC не пробился (symmetric NAT без TURN), синк продолжает работать через мастеров.

## Использование

```ts
// Создание комнаты
const room_land = this.$.$giper_baza_room_grab()

// Подключение (реактивный цикл, держите run() востребованным)
const room = this.$.$giper_baza_room.join( room_land.link().str )
room.run()

room.mates() // лорды других онлайн-пиров
room.ports // установленные прямые порты по лордам

// TURN при необходимости
$giper_baza_room.ice = [ { urls: 'turn:...', username: '...', credential: '...' } ]
```

## Файлы

- `room.ts` - протокол: схема данных комнаты, ключи сигналов, роли, окно свежести. Изоморфный, покрыт тестами.
- `room.web.ts` - движок: RTCPeerConnection, обмен sdp через комнату, регистрация портов в yard. Только браузер.
- `room.test.ts` - тесты протокола, включая полный rendezvous двух лордов через один ленд.
- `demo/` - живое демо: `/giper/baza/room/demo/-/test.html`, комната в `?room=`, список пиров с relay/direct и общий текст.
